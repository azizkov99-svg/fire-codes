# مرجع أكواد الحريق

مرجع موحّد لأكواد الحريق والسلامة يجمع NFPA والكود السعودي والدفاع المدني وأرامكو وHCIS وAPI وISO وIEC وIEEE وOSHA وILO ونظام العمل وNCA، مع بحث مفهرس وخريطة ارتباطات ومراجعة مشاريع لكشف النواقص.

تم بواسطة **ABDULAZIZ ALYEMN**.

## التشغيل
تطبيق ويب ثابت بدون خادم. يكفي رفع المجلد على أي استضافة ثابتة.

- **GitHub Pages:** أنشئ مستودعاً جديداً، ارفع محتويات هذا المجلد إلى الفرع `main`، ثم Settings ← Pages ← Source: `Deploy from a branch` ← `main` / `root`. يصبح الرابط `https://<اسم-المستخدم>.github.io/<اسم-المستودع>/`.
- **Netlify:** اسحب المجلد إلى app.netlify.com/drop.
- **محلياً:** `python3 -m http.server` داخل المجلد ثم افتح `http://localhost:8000`.

## الذكاء الاصطناعي
«اسأل Claude» و«المراجعة المعمّقة» تعمل بمفتاح API يضعه كل مستخدم من صفحة الإعدادات. المفتاح يُحفظ في متصفح المستخدم فقط ويُرسل مباشرة إلى `api.anthropic.com`. باقي المزايا تعمل بدون مفتاح.

## الخصوصية وحقوق النشر
الملفات المرفوعة تُفهرس وتُحفظ في متصفح المستخدم (IndexedDB) ولا تُرفع لأي خادم. المرجع المدمج يحوي ملخّصات بصياغة خاصة وليس نصوص المعايير المحمية بحقوق النشر.
